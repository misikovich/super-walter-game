# super-walter-white-rv

Created in [T3 Code](https://t3.codes).

## Синий Дрифт — 3D картинг в пустыне

Открой `index.html` в браузере (двойным кликом, сервер не нужен; Three.js грузится с CDN).
Музыка играет из `assets/theme.mp3`.

**Управление:** W/↑ газ, S/↓ тормоз, A/D руль, Пробел — дрифт (отпусти, чтобы получить турбо),
E/Shift — предмет, M — музыка, Esc — пауза. Ростер и параметры машин — массив `ROSTER` в начале скрипта.
